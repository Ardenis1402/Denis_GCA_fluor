# Data for: "Towards a common surface complexation model for describing fluoride adsorption on Andosols"

**Authors:** Arnaud Denis, Pierre Delmelle
**Affiliation:** Environmental Sciences, Earth and Life Institute, UCLouvain, Louvain-la-Neuve, Belgium
**Corresponding author:** Arnaud Denis ([arnaud.denis@hotmail.be](mailto:arnaud.denis@hotmail.be))
**Manuscript submitted to:** Geochimica et Cosmochimica Acta

## Overview

This repository contains the dataset underlying the results presented in the manuscript above. The data cover batch fluoride adsorption experiments performed on four Icelandic Andosols (Vitric, Brown, Gleyic and Histic Andosols; VA, BA, GA and HA, respectively), together with the associated aqueous speciation calculations and surface complexation model outputs.

## File description

**`Data.xlsx`** contains the following sheets:

| Sheet | Content |
|---|---|
| `Oxa and pyro extraction` | Ammonium oxalate- and sodium pyrophosphate-extractable Al, Fe and Si contents used to estimate allophane/imogolite and ferrihydrite contents (Table 1) |
| `pH0` | Replicate pH measurements before and after soil equilibration, used to estimate the point of zero net proton charge (pH0) of each soil (Table S1) |
| `Cations, anions and DOC` | Cation concentrations measured by ICP and dissolved organic carbon (DOC) measured by TOC-L analysis, together with the average concentrations, volumes and masses used as MINTEQ input data for cations, anions and DOC |
| `F and Al speciation` | Fluoride and aluminium aqueous speciation (%), MINTEQ output data |
| `Adsorption envelopes` | Fluoride adsorption envelope data (mg F kg⁻¹ soil) across pH 2.8-8 for each soil |
| `SI Fluorite` | Fluorite saturation index of the equilibrated experimental solutions |
| `SCM results` | Surface site speciation model results for the SCM1_noAl, SCM1_wAl, SCM2_noAl and SCM2_wAl configurations |
| `12.5 and 50 Fppm data` | Fluoride adsorption data at initial concentrations of 12.5 and 50 mg L⁻¹, and dissolved Al measured after equilibration |

Each sheet is organised by soil (VA, BA, GA, HA), following the structure of the corresponding tables and figures in the manuscript and its Supplementary Material.
